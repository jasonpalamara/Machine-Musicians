# Making Machine Musicians Max/MSP Patches

This repository contains Max/MSP example patches that accompany the book *Making Machine Musicians: AI for Live Musical Performance* by Jason Palamara.

https://www.routledge.com/Making-Machine-Musicians-AI-for-Live-Musical-Performance/Palamara/p/book/9781032840543

Author's note:
Beyond the first few chapter's tutorials, this GitHub repository intentionally does not include completed versions of tutorial patches. Readers are encouraged to build each system themselves. Companion materials of tutorials beyond Chapter 5 include only snippets, datasets, media assets, and complete applications that are impractical to recreate during the tutorials. That said, if you find you are REALLY stuck and can't get something to work, email me at japalama@iu.edu and either myself or one of the students in my Machine Musician Lab will email you back with a solution (up to and including POSSIBLY MAYBE emailing you the full patch shown in the book...but it'd be better for you to build your own*). -DrJP

## Figures

This folder is optional to download, but may be useful as you are building patches on your own.

## How to Use

1. Download and install [Max/MSP](https://cycling74.com).
2. Open the `.maxpat` files directly in Max.
3. Follow the instructions in the text regarding each patch or snippet.

Questions or suggestions? Open an issue or email me at [japalama@iu.edu].

## Errata / Known errors in the published edition of the book
Who is this book for?, page 3, instructions for downloading and installing the patches found in the GitHub repository.
Somewhat hilariously, the directions for actually downloading and installing the repository found here on GitHub was incompletely described in the actual text of the book. Here's what I should have written:

**Repository Access**
To obtain the companion materials, visit:
https://github.com/jasonpalamara/Machine-Musicians

There, you will find folders and .maxpat files corresponding to specific
chapters and topics. To download all materials:
1. Click the green “Code” button.
2. Select “Download ZIP.”
3. Extract the downloaded archive and open the patch files using Max/MSP (on a Mac, this can be accomplished easily by double clicking on the zipped file, on a PC, right click on the zipped file and click "extract all," then choose a destination for the folder. Make note of wherever this folder ends up as you will need it later.
4. The text of the book will periodically instruct you to find things in this folder, so don't lose it (though if you do you can always download it again from GitHub).

**Chapter 5**
Image 5.4 - In the published first edition, image 5.4 includes the "send MIDIears" object before it is discussed in the text. This will be fixed in future editions, but for now, the patch should work as shown anyway assuming the reader builds it exaclty as shown. Read further into Chapter 5 for an explanation of send objects and their usage here.
